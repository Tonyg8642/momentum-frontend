# Momentum Frontend

A React frontend for a clothing app that fetches and displays items from a backend API.

## Features
- Fetches clothing items from a backend API
- Displays items dynamically using React components
- Loading state while fetching data
- Fallback data if API fails
- Clean component-based architecture

## Tech Stack
- React
- JavaScript
- HTML
- CSS

## How It Works
The app sends a request to the backend (`localhost:3001/items`) and displays clothing items. If the API fails, fallback data is used to prevent crashes.
